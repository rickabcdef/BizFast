# m11_admin 运营管理后台（P1）

负责人：B+D（分享转化 M8-04 为研发 D，其余为研发 B）· 状态：网页端已完成

## 功能
- **数据看板（M11-05）**：转化率 / 付费单数 / 收入 / 退款率 KPI 卡 + 近 7 天趋势
  （纯 CSS 绘制，无第三方图表依赖；数据延迟 ≤ 5 分钟）。
- **用户管理（M11-01）**：列表 / 筛选（会员状态、关键词）/ 详情（会员状态、消费记录）/
  风控标记 / 导出 CSV。
- **订单管理（M11-02）**：列表 / 状态筛选 / 退款处理（同意原路退回、驳回记录原因）/
  导出对账表。
- **商机库管理（M11-03，P0）**：列表 / 状态筛选 / 批量导入（粘贴 CSV，后端校验入库待审）/
  通过或驳回。
- **内容审核（M11-06）**：待审内容（商机文案 / 交付物文案），命中敏感词提示，
  通过或拦截。
- **提示词配置（M11-04）**：在线编辑 AI 提示词与模型路由，保存后无需发版立即生效。
- **权限管理（M11-07）**：管理员 / 运营 / 客服三级角色，权限开关（管理员基础权限防锁死），
  保存即生效并记录操作人。
- **审计日志（M11-08）**：关键操作留痕，按操作人 / 动作筛选，导出 CSV，保留 ≥ 180 天。
- **分享转化（M8-04）**：研发 D 的模块，独立 Tab 保留。

## 登录
- 后台为内部角色系统（管理员 / 运营 / 客服），进入前需登录。
- 开发 Mock：任意非空账号密码可进入；生产环境 `POST /api/admin/login`，
  密钥走环境变量，绝不进代码库。
