# m9_notify 消息与提醒

- 负责人: **A**
- 优先级: **P1**
- 概述: 站内消息中心（订单/交付/退款/活动/系统）+ 未读红点、端通知能力如实标注（M9-02/03/04）、
  商机库更新提醒（M9-05）、免打扰时段（M9-06，营销类不推送、交易类照常）。

## 需求点
PRD 第 4.9 节仅给出标题，落地口径见 `backend/app/services/notify.py` 顶部注释。

## 入口
- 页面路由：`pages/m9_notify/index`
- 页面内入口：A 负责的 M2 / M3 / M5 页面右上角「🔔 消息」按钮（带未读红点）。
- 说明：个人中心（M10，负责人 D）的入口后续由 D 侧补充，本页不依赖它即可独立访问。

## 端差异（必须如实标注，不误导用户）
Web 端受浏览器限制**不支持后台通知**，`/api/notify/subscribe` 会返回 `supported=false`，
开关置灰并给出原因说明；生成完成后走页面内提示 + 短信/邮件提醒（PRD 8.2）。
