## 协作约定

- 每人基于 `pm` 拉 `dev/<module>`，PR 合回 `pm`。
- 改接口 → 同步更新 `api-contract.md` 与 `frontend/src/types/index.ts`。
- 公共能力（鉴权、错误码、平台适配）优先沉淀到 `core/` 与 `utils/`，避免重复。
- P0 模块为网页版第 1–4 周上线门槛，优先于 P1。
