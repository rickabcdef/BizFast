## 关键业务约束（已被测试锁定）

1. **券预览价 == 真实下单实付价**。金额口径唯一收敛到 `backend/app/services/money.py` 的 `amount_label()`，
   前端不重复实现四舍五入，避免「券后价」与按钮价格差一分钱。
2. **优惠券不可叠加**，靠 `CouponRedemption.order_id` 唯一约束在**数据层**杜绝，而非仅在业务层判断。
3. **风控命中不拦截**，只标记人工审核 —— 避免误伤真实用户，且保留可审计痕迹。
